# АЗИ — казахская карточная игра

Android-версия традиционной карточной игры АЗИ для компании из 2–6 человек. Можно тренироваться с ботами или создать комнату по коду и сыграть с друзьями онлайн.

Текущая версия: **1.5** (`versionCode 7`). Минимальная версия Android — **7.0 (API 24)**.

## Возможности

- партии на 2–6 игроков;
- одиночная практика с ботами;
- приватные онлайн-комнаты по коду приглашения;
- торги: чек, уравнять, повысить ставку или спасовать;
- три взятки в каждой раздаче и состояние АЗИ при ничьей;
- 12 вариантов рубашек карт;
- анимация раздачи закрытых карт и звуковые эффекты;
- игровой чат, рейтинг и история партий;
- вертикальное лобби и полноширинный горизонтальный игровой стол.

## Как проходит партия

В игре используется 27 карт: перед началом одна масть исключается из колоды, после чего каждому участнику раздаются три карты. Игроки делают ставки, затем разыгрывают три взятки. Нужно соблюдать масть первого хода, если карта этой масти есть на руках. Побеждает участник, взявший больше взяток. При равенстве лидеров объявляется АЗИ, а банк переносится в следующую раздачу.

Подробные правила доступны в меню внутри приложения.

## Игровой стол 1.5

Соперники размещены вдоль верхнего края, сыгранные карты — в центре, а рука игрока и контекстные действия — внизу. Банк и козырь имеют отдельные читаемые зоны. Карты сохраняют вертикальные пропорции и не растягиваются даже при шести участниках. Активный игрок выделяется бирюзовой рамкой, а анимация раздачи летит к фактическому месту каждого профиля и каждой карты руки.

## Сборка

Понадобятся Android Studio с JDK 17 и Android SDK 36.

```powershell
./gradlew.bat :app:assembleDebug
```

APK появится в `app/build/outputs/apk/debug/app-debug.apk`.

Запуск основных тестов:

```powershell
./gradlew.bat :app:testDebugUnitTest
```

В проекте есть тесты правил ставок, комнат и сетевого обмена, поддержки шести игроков, ориентации экрана, размещения карт и профилей, увеличенного шрифта и анимации раздачи.

## Структура проекта

- `app/src/main/java/com/example/model` — карты, игроки и правила;
- `app/src/main/java/com/example/viewmodel` — состояние и ход партии;
- `app/src/main/java/com/example/network` — комнаты и обмен игровыми событиями;
- `app/src/main/java/com/example/ui` — интерфейс Jetpack Compose;
- `app/src/test` — модульные и UI-тесты.

## Важно об онлайн-режиме

Онлайн-обмен предназначен для дружеской игры с условными фишками. Текущая версия использует публичный транспорт ntfy.sh и не предоставляет серверный античит, сквозное шифрование или гарантированное восстановление партии после длительного разрыва соединения. Не используйте игру для ставок реальными деньгами.
